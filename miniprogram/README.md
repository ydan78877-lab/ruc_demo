# 人大中法学生助手微信小程序

这是从现有 React + Vite 网页 Demo 中迁移出的微信小程序工程。本目录使用 Taro 4 + React 18，以同一份页面、交互、数据和样式源码同时生成 Codex 本地预览与微信小程序代码。

## 本地配置

安装依赖后，从示例文件创建仅存在于本机的配置：

```bash
npm ci
cp .env.example .env.local
cp cloudbaserc.example.json cloudbaserc.json
```

`develop` 必须配置开发 CloudBase 环境；只有项目所有者的本机才可配置内测正式环境。不得提交 `.env.local` 或 `cloudbaserc.json`。

## Codex 本地预览

```bash
npm run dev:h5
```

打开 [http://127.0.0.1:10086/](http://127.0.0.1:10086/) 即可查看。这个预览保留小程序自定义导航和微信胶囊，不使用 iPhone 外壳。H5 构建输出到 `dist-h5/`，不会覆盖微信开发者工具读取的 `dist/`。

## 当前已迁移

- 概览、功能中心、25中法保研目标页
- 毕业条件自查、推免资格进度、中文简历材料展示
- 经历录入、完整档案、个人信息与 CloudBase 账号数据
- 班级与课程、校园事项、个人提醒与课程资料
- 独立电脑端管理后台对应的账号与权限接口
- 模版库
- 由四张飞书 CSV 生成的案例库：115 条案例、24 所学校、9 篇专访、21 项页面配置

生成案例数据时会过滤后台真实姓名和备注字段。小程序内不包含四张原始 CSV，避免把运营后台字段打进前台包。

## 微信开发者工具导入

1. 在本目录执行：

   ```bash
   npm install
   npm run build:weapp
   ```

2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择本 `miniprogram` 文件夹，不要只选择 `dist`。
4. 工具会从 `project.config.json` 读取 AppID `wxadf2543c5aec62b3`，小程序代码目录为 `dist/`。
5. 开发时可运行 `npm run dev:weapp`，保存源码后自动重新编译。

需要同时验证两个端时执行：

```bash
npm run check:sync
```

这会依次完成类型与数据校验、H5 构建、微信小程序构建，并再次检查微信主包。页面修改只需改 `src/` 一次；Codex 预览与微信小程序会从同一份源码生成。

## 更新案例库

运营人员重新从飞书导出四张 CSV 后，把它们放在同一文件夹，执行：

```bash
npm run import:cases -- /CSV所在文件夹
npm run build:weapp
```

脚本识别：`offer表.csv`、`学校表.csv`、`专访表.csv`、`页面配置表.csv`。

## 校验

```bash
npm run check
```

校验包括 AppID、案例数据是否生成、隐私字段是否排除，以及编译后的微信主包是否低于 2MB。

## 当前边界

- 学生个人数据、班级/课程空间、共享事项、个人事项和课程资料通过 CloudBase 云函数按微信账号隔离。
- 案例库仍是随代码发布的脱敏只读快照，只有运营人员通过 CSV 导入脚本更新。
- 开发环境只允许模拟数据，不得复制或访问内测正式环境的真实用户资料。
- 技术合作者可修改小程序、云函数和管理后台代码，但不获取正式数据库、超级管理员和发布凭据。
- 微信体验版与正式版由项目所有者统一上传。
